## Что сделано (по порядку)
1. **Отчёт по контактам за всё время.** `avito_cleanup.py`: собрал все 967 объявлений (604 active + 363 old), статистику `uniqContacts` через `POST /stats/v1/accounts/{uid}/items`. Заявленный лимит глубины 270 дней обходится окнами назад в прошлое — реально собрано с 2019 года. Итог: **893 с 0–1 контактами (DELETE), 39 на активацию (ACTIVATE), 35 оставить (KEEP)**. Пользователь подтвердил удаление всех 893.
2. **Прямых методов удаления/активации в публичном API Авито НЕТ** (все кандидаты эндпоинтов — 404, проверено пробами и по всем 25 OpenAPI-спекам developers.avito.ru).
3. **Чистка через автовыгрузку.** Старый фид (b2b-help конструктор) умер — 404. Пользователь прислал официальный Excel-экспорт автозагрузки (924 объявления). `build_feed_xlsx.py` собрал `feed.xlsx` из 65 строк (35 KEEP + 30 ACTIVATE), профиль автовыгрузки переключён на raw-ссылку файла в репо, `POST /autoload/v1/upload`. Результат: **853 снято с публикации**; вместе с уже снятыми — **все 893 DELETE в статусе «снято»**.
4. **Активация 30 снятых не прошла.** Сначала ошибки 1073 (пустые обязательные поля услуг) — исправлено заполнением `Consultations=Есть, WorkWithContract=Да, Prepayment=Нет` (вторая выгрузка). Затем упёрлось в «Истёк срок размещения»/платное повторное размещение при `allow_pay_over_limit=false`. **Пользователь решил: не активировать, оставить как есть.**
5. **Цена просмотра 86 ₽** выставлена на все 35 активных (`POST /cpxpromo/1/setManual`, actionTypeID=5, bidPenny=8600, дневной лимит не задан) — 35 ok / 0 fail. Ручная ставка заменила автостратегию (была 800 ₽/день).
6. **Инцидент с лимитом публикаций:** расписание автовыгрузки (uploadMode=auto, все слоты) самозапускало прогоны, каждый заново публиковал объявления из файла → съеден месячный лимит размещений (~300+ по оценке пользователя). **Автовыгрузка полностью выключена** (`autoload_enabled=false`) — списания остановлены.

## Важные факты об API Авито (проверено на практике)
- Токен: `POST /token` (client_credentials); просроченный токен → **403**, не 401.
- Список: `GET /core/v1/items` (per_page<100, лимит 25 req/min); статистика: `POST /stats/v1/accounts/{uid}/items` (≤200 id, окна по 270 дней работают и для старых периодов).
- Удаления/активации объявления в API нет; управление — только автовыгрузкой: валидная строка в файле → публикация/активация, отсутствие → снятие.
- Автовыгрузка: `GET/POST /autoload/v2/profile`, `POST /autoload/v1/upload` (1 раз/час), отчёты `GET /autoload/v4/uploads` (+`/current/items`, ~5 записей на страницу, жёсткий rate limit), маппинг `GET /autoload/v2/items/ad_ids`.
- Обязательные поля услуг в фиде: Consultations, WorkWithContract, Prepayment (ошибка 1073, если пустые).
- Ставки: `POST /cpxpromo/1/setManual` (bidPenny в копейках, actionTypeID=5, лимит 20 req/min); каждый прогон автовыгрузки = повторные публикации и расход лимита размещений — расписание держать выключенным, запускать вручную.
