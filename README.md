# evgeniaPavito — чистка объявлений Авито

Скрипт `avito_cleanup.py` собирает все объявления аккаунта (статусы `active,old`),
считает уникальные контакты по каждому за максимально доступный период и
классифицирует:

- **0–1 контакт → DELETE** (удалить)
- **2+ контактов, снято с публикации → ACTIVATE** (вернуть в актив)
- **2+ контактов, активно → KEEP** (не трогать)

## Использование

```bash
cp .env.example .env   # вписать AVITO_CLIENT_ID / AVITO_CLIENT_SECRET
pip install -r requirements.txt

# 1) отчёт без изменений
python3 avito_cleanup.py

# 2) выполнить действия из проверенного отчёта (спросит подтверждение DELETE)
python3 avito_cleanup.py --execute --report reports/report_YYYY-MM-DD_*.csv
```

Отчёты и лог пишутся в `reports/` (в git не попадают). `--resume` продолжает
прерванный execute по `reports/state.json`.

## Ограничения API Авито

- Статистика контактов отдаётся окнами; скрипт шагает окнами по 270 дней в
  прошлое, пока API принимает запросы. Реально покрытый период пишется в отчёт
  (`stats_from`), объявления старше него помечены `older_than_stats=yes`.
- В публичных OpenAPI-спеках Авито **нет** методов удаления/активации
  объявлений. `--execute` сначала пробует известные недокументированные
  эндпоинты на одном объявлении; если ни один не работает — остаётся
  автовыгрузка (XML-фид) или массовые действия в личном кабинете
  (в отчёте есть ссылки на объявления).
- Лимит списка объявлений — 25 запросов/мин; на больших аккаунтах сбор
  занимает несколько минут. 429 и 5xx ретраятся автоматически.
- Просроченный токен Авито возвращает 403 (не 401) — учтено.
