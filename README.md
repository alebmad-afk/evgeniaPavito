# Авито — «ИП Поршнева Е.Д.» (user_id 171666816)

Фид автозагрузки: **30 объявлений × 18 городов (UTC+3 и UTC+4) = 540 строк**
на ID уже снятых объявлений + 31 активное объявление без изменений.

## Файлы

| Файл | Назначение |
|------|-----------|
| `build_city_feed.py` | сборка `feed.xlsx` из официального экспорта автозагрузки |
| `cities.py` | 18 городов (спрос на бухучёт, не дальше часа от МСК) и строки `Address` |
| `data/ads_texts.json` | тексты 30 объявлений (выгружены с Яндекс.Диска клиента) |
| `feed.xlsx` | готовый фид (его качает Авито по raw-ссылке) |

## Как пересобрать

```bash
python3 build_city_feed.py exports/<свежий_экспорт>.xlsx feed.xlsx
```

Экспорт берётся в ЛК Авито (Автозагрузка → выгрузить в Excel) — в нём нужны
служебные колонки `AvitoId` и `AvitoStatus`. Каталог `exports/` в `.gitignore`.

## Фото

Лежат на привязанном Яндекс.Диске в `avito_feed/porshneva/`:
`cover_01..30.jpg` (уникальная обложка каждого объявления) и
`common_02..10.jpg` (9 общих фото — в исходных папках они побайтно одинаковы).
В фиде это `yandex_disk://avito_feed/porshneva/...` через ` | `.

## Правила работы с аккаунтом

* Секреты (`AVITO_CLIENT_ID/SECRET`, `YADISK_TOKEN`) — только в `.env`.
  **Репозиторий публичный**, в коммиты они не попадают.
* Автовыгрузка выключена намеренно: почасовое расписание самозапускало прогоны,
  каждый прогон = повторная публикация = расход месячного лимита размещений.
  Перед включением расписание сузить до одного слота.
* `allow_pay_over_limit = false` — защита от списаний сверх лимита, не менять.
* 31 активное объявление (оплачены до 04.09.2026, ставка просмотра 86 ₽)
  переносятся в фид без изменений: отсутствие строки в файле снимает объявление.
* Строки со статусом «Истёк срок публикации» в фид не берём — их возврат
  требует платного повторного размещения.
