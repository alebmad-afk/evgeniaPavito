# Авито — «ИП Поршнева Е.Д.» (user_id 171666816)

Фид автозагрузки: **30 объявлений × 18 городов (UTC+3 и UTC+4) = 540 строк**
на ID уже снятых объявлений + 31 активное объявление без изменений.

## Файлы

| Файл | Назначение |
|------|-----------|
| `build_city_feed.py` | сборка `feed.xlsx` из официального экспорта автозагрузки |
| `cities.py` | 18 городов (спрос на бухучёт, не дальше часа от МСК) и строки `Address` |
| `data/ads_texts.json` | тексты 30 объявлений (выгружены с Яндекс.Диска клиента) |
| `data/paid_until_20260904.txt` | AvitoId, по которым размещение ещё оплачено — только они годятся под перезапуск |
| `feed.xlsx` | готовый фид (его качает Авито по raw-ссылке) |

## Как пересобрать

```bash
python3 build_city_feed.py exports/<свежий_экспорт>.xlsx feed.xlsx <прошлый_feed.xlsx>
```

Третий аргумент (по умолчанию — сам `feed.xlsx`) фиксирует раскладку прошлого фида:
пары «объявление ↔ город» не переезжают на другие ID. Это важно — у уже
опубликованного объявления смена региона может пойти как новое размещение.

Экспорт берётся в ЛК Авито (Автозагрузка → выгрузить в Excel) — в нём нужны
служебные колонки `AvitoId` и `AvitoStatus`. Каталог `exports/` в `.gitignore`.

## Правила работы с аккаунтом

* Секреты (`AVITO_CLIENT_ID/SECRET`, `YADISK_TOKEN`) — только в `.env`.
  **Репозиторий публичный**, в коммиты они не попадают.
* Автовыгрузка выключена намеренно: почасовое расписание самозапускало прогоны,
  каждый прогон = повторная публикация = расход месячного лимита размещений.
  Перед включением расписание сузить до одного слота.
* `allow_pay_over_limit = false` — защита от списаний сверх лимита, не менять.
* 31 активное объявление (оплачены до 04.09.2026, ставка просмотра 86 ₽)
  переносятся в фид без изменений: отсутствие строки в файле снимает объявление.
* Строки со статусом «Истёк срок публикации» в фид не берём — их возврат
  требует платного повторного размещения.

## Состояние аккаунта на 04.09.2026

Августовская партия отвалилась: у всех было оплачено размещение до 04.09.
Снимок в `snapshots/` (`recon_*.json` — статусы и профиль, `feed_current_*.xlsx` —
фид, скачанный из Авито; он же основа для следующей сборки).

```
active 4 · old 961 · blocked 2
```

Переиспользование архивных ID больше ничего не экономит — оплаченный срок истёк
у всех, возврат архивного стоит столько же, сколько новое объявление. Дальше
работаем новыми строками (пустой `AvitoId`).

Два заблокированных — код **2015 «Повторное размещение»**, оба конфликта внутри
одного города между близкими услугами (Сочи и Казань: «Бухгалтер для строительной
компании» против «Бухучёт по строительным объектам»). Кросс-город одинаковый
заголовок 2015 не ловит. Отсюда правило раскладки: **в одном городе не больше
одного объявления из смыслового кластера**, и уникальная первая фотография
у каждого объявления.
